# Frontend

React 19 + Vite, Mantine for the admin UI.

```bash
npm install
npm run dev    # http://localhost:5173
npm run lint
```

- `src/` — the React app (currently a starter page).
- `public/afisha.html` — static HTML/CSS movie list from the HTML/CSS
  exercise, served at http://localhost:5173/afisha.html. It will be
  replaced by React components (MovieList, MovieCard) when the movie
  list page is built.

How to run the whole project: see the root README.
